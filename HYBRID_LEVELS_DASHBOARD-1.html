Hybrid Formula (Non-Repainting)

🔢 Calculated each night at 10pm Spain — same method for both pairs

// Jenkins Square Root from first 60-min extreme
Root = √(Pivot × 10000)
Level = (Root ± i)² / 10000   where i ∈ {0.25, 0.5, 0.75, 1.0, 1.5, 2.0}

// Combined with structural levels
AllLevels = StructuralLevels ∪ JenkinsLevels
NearestSupport = max(level < Open)
NearestResistance = min(level > Open)
Levels are fixed at calculation time and do not repaint. ATR is measured at the same 10pm Spain close for each pair.
